# Mockup - CineClick

Wireframe estático para visualizar las pantallas antes del desarrollo funcional.

## Páginas incluidas

- **Inicio (Landing)** - Hero section + pasos para comprar
- **Funciones** - Listado de funciones (producto = función) con acciones
- **Detalle** - Información completa de la función
- **Compra** - Flujo de 3 pasos (butacas, cliente, pago)
- **Panel Admin** - Listado + acciones CRUD
- **Crear/Editar Función** - Formularios admin
- **Grupo** - Integrantes + descripción compañía
- **Login** - Formulario de login

## Cómo ver

Abrir `frontend/mockup/index.html` en el navegador. Todos los links son internos con anclas (#) para simular navegación.
